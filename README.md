**Aplikasi Administrasi Sekolah berbasis Laravel, Bootstrap & MySQL**

Repositori ini merupakan platform sistem administrasi sekolah yang dikembangkan menggunakan framework **Laravel** untuk backend, **Bootstrap** untuk frontend, dan **MySQL** sebagai basis data. Solusi ini dirancang untuk mempercepat proses administrasi, memudahkan pengelolaan data, dan meningkatkan efisiensi operasional di lingkungan sekolah.

---

## 🚀 Fitur Utama

- **Manajemen Data Siswa, Guru, dan Staff**
- **Pengelolaan Jadwal Pelajaran & Absensi**
- **Manajemen Nilai & Rapor**
- **Pengelolaan Surat, Dokumen, dan Arsip**
- **Notifikasi & Informasi Sekolah**
- **Dashboard Statistik & Laporan**

## 📦 Instalasi & Konfigurasi

### 1. Clone Repository

```bash
git clone https://github.com/agusbayu13/Sistem-Administrasi-Sekolah.git
cd Sistem-Administrasi-Sekolah
```

### 2. Install Dependencies

```bash
composer install
npm install
```

### 3. Konfigurasi Environment

Salin file `.env.example` menjadi `.env` dan sesuaikan konfigurasi database di dalamnya.

```bash
cp .env.example .env
```

### 4. Generate Key & Migrasi Database

```bash
php artisan key:generate
php artisan migrate
```

### 5. Jalankan Server Lokal

```bash
php artisan serve
```

Akses aplikasi via browser: `http://localhost:8000`
